# Support

Thank you for using **mini-scanner**.

This document explains how to get help, report problems, and contribute to the project.

---

# Getting Help

Before opening an issue, please:

- Read the README.
- Check existing GitHub Issues.
- Review the documentation.
- Ensure you are using the latest version.

---

# Reporting Bugs

If you believe you have found a bug:

1. Search existing issues.
2. If the issue has not been reported, create a new **Bug Report**.
3. Include:
   - Operating System
   - Python version
   - mini-scanner version
   - Steps to reproduce
   - Expected behavior
   - Actual behavior
   - Complete error output

---

# Requesting Features

Feature requests are welcome.

When opening a feature request, please explain:

- The problem you are trying to solve
- Your proposed solution
- Alternative approaches considered
- Why the feature would benefit users

---

# Security Issues

**Do not report security vulnerabilities through public GitHub Issues.**

Please follow the instructions in:

`SECURITY.md`

If GitHub Security Advisories are enabled, use the private reporting feature.

---

# Discussions

Use GitHub Discussions (if enabled) for:

- Questions
- Ideas
- Design discussions
- Community support
- General feedback

---

# Pull Requests

Contributions are welcome.

Please read:

- CONTRIBUTING.md
- CODE_OF_CONDUCT.md

Before submitting a pull request, ensure:

- Tests pass
- Documentation is updated if necessary
- Code follows the project's style
- Commits are clean and focused

---

# Supported Versions

Only the latest stable release is supported.

Older versions may not receive bug fixes or security updates.

---

# Response Times

While response times cannot be guaranteed, the project aims to:

| Request Type | Target Response |
|--------------|----------------:|
| Bug Report | Within 7 days |
| Feature Request | Within 14 days |
| Pull Request Review | Within 7 days |
| Security Report | Within 3 business days |

---

# Project Scope

mini-scanner is intended to be:

- Lightweight
- Cross-platform
- Easy to understand
- Well tested
- Open source
- Educational and practical
