# Roadmap

This roadmap outlines the planned direction for **mini-scanner**. Features may change as the project evolves based on community feedback and development priorities.

---

# Vision

Build a fast, reliable, and extensible Python-based network scanner suitable for:

- Learning networking concepts
- Security assessments
- System administration
- Automation
- Open-source contribution

---
