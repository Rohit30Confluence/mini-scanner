## Versioning Policy

This project follows Semantic Versioning.

- MAJOR version for incompatible API changes.
- MINOR version for new functionality.
- PATCH version for bug fixes.

Examples:

- 1.0.0 → Initial release
- 1.1.0 → New features
- 1.1.1 → Bug fixes
- 2.0.0 → Breaking changes
